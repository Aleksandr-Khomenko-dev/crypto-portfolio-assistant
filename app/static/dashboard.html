✈ Настройка Telegram уведомлений

Получай мгновенные алерты о пампах, сигналы и утренний дайджест прямо в Telegram.

1
Создай бота через BotFather

Напиши @BotFather в Telegram → /newbot → получи токен вида 123456:ABC-DEF…

2
Узнай свой Chat ID

Отправь любое сообщение своему боту, затем открой в браузере:
https://api.telegram.org/bot<TOKEN>/getUpdates
Найди "chat":{"id": 123456789}

3
Введи данные ниже

Токен сохранится в конфиге сервера, Chat ID — в настройках портфеля.

⚠ После сохранения перезапусти сервер с переменной CPDA_TELEGRAM_BOT_TOKEN=<твой_токен>
